# ✂️ Narjin — Beauty Salon Reservation Platform

A modern and scalable online reservation platform designed for **men’s and women’s beauty salons**.  
Narjin helps customers easily book appointments online while providing salon owners with powerful tools for managing schedules, services, staff, and reservations.

This project focuses on delivering a smooth digital booking experience with a clean and professional architecture.

---

# 🚀 Overview

**Narjin** is a multi-service salon booking platform built to simplify appointment management for:

- 💇 Women’s Beauty Salons
- 💈 Men’s Barber Shops
- 💅 Nail & Beauty Services
- 🧖 Skincare & Spa Centers

The platform provides a modern scheduling system with user-friendly booking workflows and scalable backend infrastructure.

# ⚙️ Installation

## 1. Clone the repository

```bash
git clone https://github.com/MErfanPld/Narjin.ir.git
```

## 2. Navigate to the project directory

```bash
cd Narjin.ir
```

---

## 3. Create virtual environment

```bash
python -m venv venv
```

---

## 4. Activate virtual environment

### Linux / macOS

```bash
source venv/bin/activate
```

### Windows

```bash
venv\Scripts\activate
```

---

## 5. Install dependencies

```bash
pip install -r requirements.txt
```

---

# ▶️ Run the Project

## Django

```bash
python manage.py runserver
```

Server will run on:

```bash
http://127.0.0.1:8000
```
